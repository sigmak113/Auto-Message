# 섭외 메세지 생성기 사용법

## ⭐ exe 만들기 (파이썬 설치 필요 없음 — GitHub Actions 사용)

내 컴퓨터에 아무것도 설치하지 않고, 브라우저만으로 진짜 Windows exe를 만들 수 있어요.
(빌드는 GitHub이 무료로 제공하는 클라우드 Windows 서버에서 진행됩니다. 이전에 배치파일이
한글 인코딩 문제로 깨졌던 것과 달리, 이 방식은 그런 문제가 아예 생기지 않아요.)

1. https://github.com 에서 무료 계정 가입 (이미 있으면 로그인)
2. 오른쪽 위 **+** 버튼 → **New repository** 클릭 → 이름 아무거나 입력 (예: `outreach-message-tool`) → **Public** 선택 → **Create repository**
3. 생성된 저장소 페이지에서 **Add file → Upload files** 클릭
4. 이 폴더 안의 파일 전체(**`.github` 폴더 포함**)를 드래그 앤 드롭으로 업로드 → 아래 **Commit changes** 클릭
   - ⚠️ `.github/workflows/build-exe.yml` 파일이 반드시 같이 올라가야 자동 빌드가 됩니다.
     탐색기에서 숨김 폴더가 안 보이면 "숨김 항목 보기"를 켜주세요. (`.github`로 시작하는 폴더라 숨김 처리될 수 있어요)
5. 상단 메뉴의 **Actions** 탭 클릭 → "Build EXE" 워크플로우가 자동으로 실행 중일 거예요
   (안 보이면 왼쪽에서 "Build EXE" 클릭 → **Run workflow** 버튼 클릭)
6. 노란 점(진행 중) → 초록 체크(완료)로 바뀔 때까지 1~2분 대기
7. 완료된 실행 결과 클릭 → 맨 아래 **Artifacts** 항목에서 `섭외메세지생성기-exe` 다운로드
8. 압축을 풀면 `섭외메세지생성기.exe`와 `templates.json`이 함께 들어있어요.
   이 두 파일을 같은 폴더에 두고 exe를 실행하면 됩니다. 받는 사람도 파이썬 필요 없이 바로 실행돼요.

## 프로그램 사용법

1. 왼쪽 **템플릿 목록**에서 상황에 맞는 템플릿을 클릭합니다.
2. 가운데 **변경할 항목 입력** 칸에 `[모집공고 제목]`, `[가이드 링크]` 같은 항목들을 채웁니다.
3. **"메세지 생성 ▶"** 버튼을 누르면 오른쪽 **미리보기**에 완성된 메세지가 나타납니다.
   (입력하는 즉시 자동으로 미리보기에 반영됩니다.)
4. **"📋 클립보드로 복사"** 버튼을 누르면 바로 복사되어, 카카오톡/이메일 등에 붙여넣기(Ctrl+V) 하면 됩니다.

## 템플릿 추가/수정/삭제

- 왼쪽 하단의 **추가 / 수정 / 삭제** 버튼으로 자유롭게 템플릿을 관리할 수 있습니다.
- 새 템플릿을 만들 때, 매번 바뀌는 부분은 반드시 대괄호 `[ ]`로 감싸주세요.
  - 예: `[모델명]`, `[촬영일정]`, `[담당자명]`
  - 같은 이름의 `[ ]`가 여러 번 등장하면, 한 번만 입력해도 전체에 자동으로 반영됩니다.
- 템플릿은 exe와 같은 폴더의 `templates.json` 파일에 자동 저장되어, 프로그램을 껐다 켜도 유지됩니다.
- `templates.json` 파일을 팀원들과 공유하면 같은 템플릿 세트를 그대로 사용할 수 있습니다.

## 코드/템플릿을 수정한 뒤 exe를 다시 만들고 싶다면

GitHub 저장소에서 `main.py`나 `templates.json`을 수정하고 다시 **Commit changes**만 누르면,
자동으로 새 빌드가 시작돼요. Actions 탭에서 새로 완료된 빌드의 Artifacts에서 최신 exe를 받으면 됩니다.
